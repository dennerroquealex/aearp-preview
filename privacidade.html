Aviso de privacidade

Informações sobre dados pessoais tratados neste protótipo.

Início / Privacidade

Rascunho para revisão institucional. Este aviso descreve o protótipo atual e deve ser validado pela AEARP antes de qualquer publicação ou tratamento de dados reais.

Dados utilizados

Os formulários de demonstração podem solicitar nome, e-mail, telefone, atribuição profissional, registro profissional, serviços, empresa, senha e foto. Quando o plugin de contato estiver ativado no WordPress, o formulário enviará os dados ao endpoint da AEARP, que encaminhará a mensagem para contato@aearp.com.br sem guardar uma cópia no banco. A incorporação do Instagram pode enviar dados técnicos ao próprio Instagram quando carregada.

Finalidades e divulgação

Os dados de cadastro são usados para demonstrar análise de acesso e gestão da associação. Nome, atribuição, serviços, atuação, contatos e foto só devem aparecer no diretório quando houver autorização específica e aprovação da secretaria. O associado pode retirar a autorização ou solicitar remoção/alteração.

Armazenamento neste protótipo

Os dados ficam no IndexedDB e no armazenamento do navegador utilizado. Não há conta central, autenticação segura, criptografia de servidor, recuperação de senha por e-mail, cópias automáticas ou compartilhamento entre dispositivos. Não use dados pessoais reais neste protótipo.

Contato e solicitações

Para dúvidas ou solicitações relacionadas a dados pessoais, entre em contato com contato@aearp.com.br. A associação deve indicar oficialmente o canal responsável e os prazos de atendimento antes da publicação.

Retenção, segurança e atualização

Os dados locais permanecem no navegador até serem removidos pelo usuário ou pela limpeza do armazenamento do site. A versão de produção deverá definir prazos de retenção, controles de acesso no servidor, registro de operações, backups protegidos e procedimento para incidentes.

Atualizado em 24/10/2026. Este texto é um rascunho informativo, não uma validação jurídica da política da associação.
